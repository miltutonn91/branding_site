# CHIFFONTE ブランディングサイト

## プロジェクトの概要

無添加シフォンケーキブランド「CHIFFONTE」のブランディングサイトです。

実店舗を持たず、受注生産を中心に活動されているクライアント様に向けて、今後のEC展開を見据えて制作しました。

ブランドの世界観や素材へのこだわりを伝え、同時制作したECサイトへ自然につながる導線を設計しています。
