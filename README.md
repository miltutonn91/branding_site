# CHIFFONTE｜ブランディングサイト

## プロジェクトの概要

無添加シフォンケーキ「CHIFFONTE」のブランディングサイトです。

実店舗を持たず、受注生産を中心に活動されているクライアントに向けて、今後のEC展開を見据えて制作しました。

親子で安心して食べられるおやつを選びたい方に向けて、素材へのこだわりや作り手の想いを伝え、同時制作したECサイトへ自然につながる構成にしています。

### サイトURL

https://miltutonn91.github.io/branding_site/

### GitHub URL

https://github.com/miltutonn91/branding_site

## デザインについて

国産・無添加素材にこだわるブランドの安心感や、作り手の想いが伝わるよう、やさしく柔らかな雰囲気を意識し、写真の選定や配色、余白を活かしたレイアウトによって世界観を表現しました。

写真とテキストの間にゆとりを持たせ、ブランドの魅力や想いが丁寧に伝わる構成にしています。PC表示では、ナビゲーションとメインビジュアルを分け、写真を大きく見せながら読み進められるレイアウトにしました。

## 開発環境構築方法

### 1. リポジトリをクローン

```bash
git clone https://github.com/miltutonn91/branding_site.git
```

### 2. ディレクトリへ移動

```bash
cd branding_site
```

### 3. ブラウザで確認

`index.html` をブラウザで開くことで、ローカル環境で表示確認できます。

本サイトは静的なHTML / CSS / JavaScriptで制作しているため、パッケージのインストールやビルド作業は不要です。
